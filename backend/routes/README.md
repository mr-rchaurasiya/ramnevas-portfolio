# Backend Routes Folder

Defines the endpoints mapping HTTP methods to corresponding controller handlers:
- **authRoutes.js**: Endpoint definitions for administration login and credentials checking.
- **projectRoutes.js**: Endpoints for dynamic creation, deletion, reading, and updating of projects.
- **skillRoutes.js**: Endpoints for dynamic management of developer skills.
- **experienceRoutes.js**: Endpoints for managing professional timeline milestones.
