# Backend Models Folder

Contains Mongoose schemas representing MongoDB collections:
- **User.js**: Model representing administrators (username, password).
- **Project.js**: Model representing projects (title, description, tags, GitHub link, live link, image URL).
- **Skill.js**: Model representing individual skills (name, level, category).
- **Experience.js**: Model representing job history, education, and credentials (company, role, duration, description).
