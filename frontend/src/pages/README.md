# Frontend Pages Folder

This folder contains page-level React components that correspond to different routes:
- **Home**: Welcome section, hero unit, summary of skills, and featured work.
- **About**: Profile story, education, certifications, and timeline/experience.
- **Projects**: Comprehensive list of projects with filtering capability.
- **Contact**: Reach out form with email integration.
- **Admin**: Dashboard for managing projects and skills dynamically (protected routing).
